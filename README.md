# scReen

compare display sizes to scale, in your browser.

## what it does

pick any two displays from a library of phones, tablets, laptops, monitors, and TVs — or enter custom dimensions. scReen renders them side-by-side at accurate physical scale so you can see exactly how they compare.

all math runs in the browser. no uploads. no tracking.

## tech stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Vitest
